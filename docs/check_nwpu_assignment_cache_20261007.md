## 数学定义

- S 为 `[49,16]` token→region 归属，每行和为 1。区域质量为列和；以候选数的对数归一化每个 token 的熵。固定 one-hot 的熵定义为 0。
- W 为 `[49,16]` region 汇总 token 的权重，每列和为 1。不同区域的重叠为 `sum_i min(W_ik,W_il)`，报告 24 对无向空间邻居均值及全部区域对最大值；有效 token 数为 `1/sum_i W_ik²`，同时保留候选支持上限比例。
  固定/soft 的候选支持上限不同，该比例的差不能直接当作有效 token 绝对数量的差；绝对数量另行报告。
- token 坐标为 `((col+0.5)/7,(row+0.5)/7)`，单位是模型输入宽度/高度。原硬分区成员的几何均值是锚点。分别计算 S 列归一化和 W 的质心偏移、关于质心的 RMS 扩散；固定 S 不偏移，但固定 W 内部 attention 可能偏移。
- 几何参照只将 soft 候选 mask 的每行均匀分配，再列归一化得到 W；没有内容信息，不是训练过的模型。它的邻居重叠约 0.640693、有效 token 数均值 18.777516、质心偏移均值 0.120128、RMS 扩散均值 0.264163。不能把这些几何自带的非零值判为学得的塌缩。
- 按每图计算标量后，对 90 图报告 mean/median/p90；不把同图的 16 个区域当 16 个独立样本。逐图逐区域和 24 对邻居细节保存在 `per_case.json`。
