## 2. 建议的数据协议：训练池与验证集分开说明

为了同时保留验证选择、避免看测试集选checkpoint，并对齐两篇方法的共同名义训练比例，建议使用以下两阶段流程。**这是本项目方案，不是声称原论文采用了同样的模型选择过程。** 实现与smoke之后再固定协议版本和文件哈希。

| 数据集 | 外层训练池 / 测试 | 校准阶段：训练 / 验证 / 测试 | 最终拟合阶段 |
|---|---|---|---|
| AID | 50% / 50%，预期5000 / 5000 | 训练池内80/20，预期4000 / 1000 / 5000，即全体40/10/50 | 只在训练池5000张上按已选规则重新拟合，最后评估5000张test |
| NWPU | 20% / 80%，预期6300 / 25200 | 训练池内80/20，5040 / 1260 / 25200，即全体16/4/80 | 只在训练池6300张上重新拟合，最后评估25200张test |
| BigEarthNet-19 | 保留现有237871 / 122342 / 119825 | 使用现有train/val/test；按val mAP选择best | **保持原方法，无新增训练池合并或重新拟合** |

单标签流程具体规则：

1. 按类别和相对路径排序后分层抽样；外层 `split_seed=42`，训练池内部 `val_split_seed=4242`，清单一经生成供所有模型复用。逐类取整已写入schema2 / scene-pool-group-v2清单；AID实测4000/1000/5000，一组同类重复按像素组隔离到train，全部图片保留。冻结清单与SHA见[执行记录](run_aid_formal_seed42.md)。NWPU已完成5040/1260/25200清单，8组同类像素重复均保持在各自单一split内，全部31500张保留；清单SHA为ce0cfef201c6aee507bc978a9d319e42b5d7d4ba3d461d61ffb74f7c2259840e。
2. `train_seed` 与上述两个seed分别保存。主比较固定split，训练seed为42/43/44；反映的是固定split下训练重复性，不能等同于原论文5次或10次随机划分重复。相同seed两模型须共享同一份清单。
3. 校准只用内部train/val。我们模型统一30轮上限，按验证OA选epoch（同分取最早），macro-F1作为次要报告指标。外部方法的超参数和迭代预算另列，调参只用内部验证集。
4. 从相同预训练来源重新初始化，在完整外层训练池上拟合已选epoch数或已定收敛预算；不从校准末轮接着训练。我们模型的Cosine调度仍保留校准阶段的30轮周期，只执行选定的轮数，不悄悄改成更短的周期。
5. 测试只在选择结束后进行。最终权重是固定预算拟合的末轮权重，不能声称是由test选出的best。为节省时间如先只交付校准best的test结果，必须标40/10/50或16/4/80，**不能写成50%或20%实际参与拟合**。

两阶段都会消耗训练时间，预算必须同时计入。比例相同仍不等于精确复现原论文：我们保存的split、选择过程和重复次数必须披露，文献结果单独标来源。
