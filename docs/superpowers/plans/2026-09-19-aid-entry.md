> Execute task by task with the executing-plans workflow. Existing linked worktree is retained; no automatic commits, pushes, GPU rentals or formal runs.

**Spec:** `docs/experiment_matrix_20260919.md`, E00 and sections 2–4, accepted by user “继续”.

## Constraints

- AID: 30 classes, 10000 images; outer training pool 50%, validation 20% of pool; seeds42/4242 distinct from training seed.
- NWPU: 45 classes, 31500 images; outer pool20%, validation20% of pool. Synthetic input is explicitly marked and smoke-only.
- Shared224 RGB transforms, AdamW3e-4/wd1e-4/batch32/Cosine30/CE; fixed sparse-hybrid K16 GAViT. No model architecture changes.
- Explicit local pretrained source and SHA; random initialization allowed only for smoke. Formal calibration/refit requires clean Git, CUDA and real validated data.
- Separate smoke/calibration/refit identities; no overwrite; no test selection. Refit binds to completed calibration and uses its selected epoch with the original30-epoch scheduler horizon.
- Preserve existing files and unrelated dirty work. No formal experiment metrics before actual runs.
