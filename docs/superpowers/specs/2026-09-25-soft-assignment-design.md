## 1. 研究问题与范围

导师要求在NWPU-RESISC45和BigEarthNet-19比较Swin、固定4×4 GAViT与可学习分组GAViT。用户同意先做设计；HGTNet/DFAGCN作者请求已由用户发送，等待期间开展本项，不取消外部方法比较。

假设：允许token根据内容改变区域归属，可能缓解固定分区混合不同内容的问题，使区域图更有用。现有失败案例和多seed波动并未证明固定分区是根因，因此本设计不保证涨分，也不把单个最高分当作成功。

本轮主要变量是**区域归属及与之配套的汇总/反馈**。保留Swin-T、224输入、最后一级7×7 token、16区域、GAT宽度/头数/层数、分类头和现有损失。新加反馈门控、改骨干层级、改区域数、改图预算、增加聚类损失均不混入首版。

交付目标：可解释的分组消融表、真实分配/图边案例、资源开销和正负结果分析。稳定提升是待实验检验的结果，而非设计承诺。

## 2. 现状与三条路线

已核对当前研究工作树代码：

- `models/region_grouping.py`：`AttentiveSpatialGrouping`的归属固定；MLP只在一个区域内部决定哪些token权重更大。
- `models/gavit.py`：硬归属通过`gather`分发反馈；残差之后立即mean pool，无后续Transformer。
- `models/graph_construction.py`：48条四邻接边来自4×4区域编号；32条特征边来自非自身、非四邻接区域的cosine top-2，方向neighbor→query。
- `models/graph_reasoning.py`：传入的cosine权重未用于GAT计算。80条是构造器输出的非自环边，不应混同于GAT内部处理后的所有边。
- `scene_classification/modeling.py`及runner目前按固定架构构建、校验和重载；只新增一个grouping类不能完成接入。

| 路线 | 能改变什么 | 代价与限制 | 建议 |
|---|---|---|---|
| A. 空间先验引导的局部软分配 | 内容决定token在原区域及邻近区域间的权重 | 仍受局部空间先验限制，不保证连通或语义纯净；可复用原图规则 | **首版采用** |
| B. 全局自由软分配 | 每个token可分给任意区域 | 区域编号不再有空间意义，需要重定义空间边；多个变化难以分开解释 | 暂不采用 |
| C. 迭代Slot Attention | 迭代竞争形成区域表示 | 增加迭代、初始化和更新机制，也需要解决空间图身份 | 暂不采用 |

可微分组有公开先例：SSN通过可微SLIC学习任务相关的超像素；Slot Attention通过多轮竞争注意力形成可交换slots。[SSN作者项目与论文](https://varunjampani.github.io/ssn/)、[Slot Attention原论文](https://papers.nips.cc/paper/2020/hash/8511df98c02ab60aea1b2356c013bc0f-Abstract.html)。本方案是针对现有GAViT的单次分配头，不是两者的复现，也不能把“软分配”本身声称为首创。

## 3. 推荐计算方式

以下超参数是首版候选值，尚非已验证最优配置；实现后先检验机制和数值，不展开网格搜索。

### 3.1 输入、候选区域与空间先验

输入`X`为`[B,N,D]=[B,49,768]`，区域数`K=16`。

沿用旧版硬分区`h(i)`，作为空间锚点的编号参考，不再作为最终归属。候选集合`C(i)`为锚点网格上距`h(i)`切比雪夫距离不超过1的区域，即含自身的局部3×3邻域，边界裁剪。这里是**分配候选范围**；建图仍为四邻接，二者不是同一种邻域。

构造固定先验`P0[i,k]`：

- `k=h(i)`时为0.9；
- 其余`k∈C(i)`均分0.1；
- 候选集以外为0。

首版不改变这两个先验比例，不学习锚点坐标、不加温度退火。0.9是保守起点，不是理论最优；冻结先验对照用于检验仅平滑分区的作用。实际初始化已不是旧版硬分区，不能声称与旧模型初始函数完全相同。

### 3.2 学习归属：在区域维度归一化

新增分配头：`LayerNorm(768) → Linear(768,128) → GELU → Linear(128,16)`，得到内容修正`U`。

最后一个Linear的权重和偏置初始化为0，第一层正常随机初始化。因此初始分配等于`P0`，随后可以被任务损失改变。首步第一层梯度可能为0；末层更新后必须验证梯度能继续传到前层，不能只检查一次backward。

计算：

`L[i,k] = log(P0[i,k]) + U[i,k]`，候选集外为`-inf`。

`log S = log_softmax(L, dim=region)`，`S = exp(log S)`。

每个token的区域权重和为1。训练和推理都使用软分配；`argmax(S)`只允许用于展示，不参与前向或替代梯度。

### 3.3 汇总区域：在token维度归一化

保留原版标量重要性网络`a_i=attn(X_i)`，避免同时取消原区域内注意力。

`W[i,k] = softmax_i(log S[i,k] + a_i)`。

`R_k = Σ_i W[i,k] X_i`，输出`[B,16,768]`。

`S`回答“一个token归属哪些区域”，`W`回答“一个区域如何汇总token”，归一化方向不同，不能用同一个归一化矩阵替代两者。

计算使用`log_softmax`和log域列归一化；不要先算极小的`S`再取log，也不要靠在所有位置加epsilon制造候选集外的权重。每个区域都有候选token；数值非有限必须报错，不能悄悄退回硬分配。

若将`S`在测试中替换为旧硬分区one-hot，保留同一`attn`参数，则`W`和区域特征应与旧版一致。这是数值回归检查，不是正式的新训练变体。

### 3.4 建图与反馈

继续以`R`计算原48+32条边及原GAT。特征值变化会自然改变top-2边，但选择规则和预算不变；不冻结旧模型的具体特征边。

48条固定边的准确含义是**空间锚点邻接先验**，不能称为学习后实际区域轮廓的接壤关系。局部候选约束保留位置联系，但不保证区域连通、质心顺序或边界吻合。可视化同时画锚点、软分配质量中心和捕获的边，并标注该区别。

GAT投影输出`F`为`[B,16,768]`。新反馈：

`T_i = Σ_k S[i,k] F_k`；`X'_i = X_i + T_i`。

后续仍为原mean pool和classifier。这里必须用`S`，不是列归一化的`W`；也不能在反馈时转成argmax后gather。旧分组继续使用原gather分支。

重要解释边界：因为反馈后立即mean pool，

`mean_i(X'_i) = mean_i(X_i) + Σ_k (m_k/N) F_k`，其中`m_k=Σ_i S[i,k]`。

因此本模型最终使用的是区域质量加权的图反馈；不能把细致的token分配图当作已证明存在后续逐token推理的证据。软分配既改变节点内容，也改变区域反馈的汇总权重。这两者属于同一分组机制；进一步分解它们需要另设消融，首版不扩展。

## 4. 接口、兼容与实验身份

建议新配置名：`grouping=soft_spatial`，首版仅允许`num_regions=16`、`edge_type=sparse_hybrid`、`integration=token_feedback`、7×7输入token。其他组合明确拒绝，不回落到kmeans。

新分组返回`(region_features, membership)`，第二项为`[B,N,K]`浮点软分配；旧分组仍返回`[B,N]`整数索引。GAViT按显式grouping分支处理并检查类型/形状，不只根据维数猜模型身份。诊断通过独立捕获接口取`S/W/log S`，不把跨batch的带梯度张量长久留在模型对象中。

首版身份字段：

| 字段 | 候选值 |
|---|---|
| assignment_version | anchor_local_v1 |
| assignment_hidden | 128 |
| assignment_radius | 1，Chebyshev距离 |
| assignment_prior_self | 0.9 |
| assignment_temperature | 1.0，固定 |
| assignment_learnable | true；冻结对照为false |
| assignment_last_init | zeros |
| pooling | attentive_log_membership |
| feedback_mapping | soft_membership |
| graph_node_geometry | anchor_index_prior |

拓扑记录明确48条anchor-prior边、32条feature边和方向；旧固定分区记录不追溯改名。metadata保存版本、全部数值、源码/权重/数据身份。新权重缺字段、显式CLI冲突、尝试与旧架构续训均报错；不依赖当前默认值猜测新权重架构。

旧分组默认值、参数键名和加载路径保持兼容。更新`run_scene.py`、`scene_classification/modeling.py`和runner的架构校验/保存/校准→refit传递，避免固定架构检查误拒新权重或重建成旧模型；BigEarthNet train/test的参数、重建和metadata必须同步。旧`train_gavit.py`/`test_gavit.py`若暂未接新模式，应继续明确拒绝它，不能提供半通入口。

共同层初始化必须可核验：新分配头使用独立且可复现的随机数作用域，不能因多初始化一个MLP而改变GAT/反馈/分类头的初始权重。固定/冻结/可学习三个GAViT变体逐键核对共同初始参数，且不加载不同的已训练checkpoint作为正式起点。数据顺序/增强的随机性记录，模型新增初始化不应消耗训练数据生成器状态。

按上述分配头计算增加102,032个参数；batch32的单个FP32分配张量为100,352字节。二者是静态计算，**不代表**完整训练显存、运行时间或GPU实测。

## 5. 验证：先证明机制工作，再讨论收益

### 5.1 本地工程检查

1. `S`非负、每行和为1、局部候选外严格为0；`W`每列和为1。验证batch1/多batch、区域覆盖和重复输入的一致性。
2. 初始化`S=P0`；经两步以上可控优化，内容扰动能改变允许位置的分配，分配头各层得到有限梯度。用分别覆盖pooling与feedback的检查排除detach、argmax、错误归一化。
3. one-hot极限下，旧区域特征、旧反馈以及eval logits一致；直接测算同一输入、同一权重，不拿近似分数代替回归。
4. 极端有限logit下前向/反向稳定；无候选、错误N/K、非有限值明确失败，不能掩盖区域失活。
5. 实际前向捕获80条构造边、方向、去重和batch隔离；这不要求top-2排序本身可微，梯度经连续节点/反馈路径传播。
6. 保存→按metadata重建→eval logits相符；旧checkpoint、CLI冲突与错误恢复均覆盖。验证冻结对照初始化与可学习版本相同，优化后仅冻结版本的分配保持不变。

### 5.2 服务器工程短测

先NWPU，再BigEarthNet，各用冻结的训练/验证子集1 epoch验证真实解码、标签、forward/backward、保存重载和退出。BigEarthNet可沿用96 train/64 val的工程规模；NWPU使用每类8 train/2 val的均衡短测。子集路径/标签和选择规则在启动前存档，不使用test。

记录首batch、完整退出、每轮耗时、峰值allocated/reserved、主进程内存、设备和软件。短测只验工程，不据短测准确率宣称改进；不得直接外推完整训练费用。

### 5.3 诊断与失效表现

每轮在固定验证样本上保存：`S`行熵、每区域质量`m_k`、相对初始质量`m_k/m_k^0`、相对先验的变化、argmax占用、区域特征相似度、图反馈/原token范数比。49个token被分成16区本来就不等大，不强制质量均衡。

“空的argmax区域”不等于软质量为0；高熵也不自动等于坍缩。重点区分：分配几乎不学习、多数区域表示趋同、少数区域承担绝大部分反馈、数值失稳。前3项是需报告的模型表现，不能当作删掉不利运行的理由。只有可证实的工程失败修复后另立运行身份。

首版无熵/均衡/重建附加损失。若出现问题，先依据日志决定是否需要下一版；不得运行中途悄悄加损失或调先验。

## 6. 消融与训练成本

| 变体 | 含义 | 回答的问题 |
|---|---|---|
| M0 Swin-T | 无区域图 | 基线 |
| M1 固定4×4 GAViT | 当前attentive_spatial | 原区域图相对基线的作用 |
| M2 冻结软分配 GAViT | `S=P0`，同分配头结构但冻结；其余照常训练 | 仅放松硬边界/平滑汇总是否已有作用 |
| M3 可学习软分配 GAViT | 从相同`P0`开始，学习分配头 | 相比M2，学习内容相关归属是否带来额外作用 |

M0/M1/M3为导师要求的最小表。M2是建议加入的单seed机制对照；先在NWPU seed42运行，不自动扩成全数据集、多seed矩阵。若未完成M2，M3−M1只能解释为整个软分组机制的差异，不能单独归因于“学习”或排除额外参数的作用。M2也不是严格的可训练容量匹配对照。

冻结对照要**独立训练**。对M3 checkpoint推理时强制`S=P0`仅是数值干预，不能充当M2正式结果。

执行顺序建议：本地检查→两数据集工程短测→NWPU seed42公共协议下的train/val候选/机制对照→冻结配置与评价规则→NWPU refit及BigEarthNet seed42训练/最终测试→审阅结果和成本→确定正式多seed批次。候选阶段仅运行NWPU校准，不refit、不看test；主要选择依据为验证OA，macro-F1和机制诊断作为辅助，近似差异不据此展开搜索。配置冻结后才做正式test，看到test后不能据此回调先验、损失或挑版本。NWPU训练池较小，优先用于发现设计问题；不能用其单seed结果承诺BigEarthNet收益。

NWPU采用已有规划的20%训练池/80%test；预计train/val/test为5040/1260/25200，最终refit训练池6300，须由真实manifest核验。使用现有scene入口的校准→refit协议及共同配方；旧70/15/15近似结果不能复用为该主表的baseline。

BigEarthNet沿用237871/122342/119825、RGB预处理、30轮、batch32、AdamW lr3e-4/wd1e-4、Cosine30、BCE、F1阈值0.5和best-val-mAP选模。保持该数据集已记录精度策略，不擅自切AMP。已有Swin/固定GAViT结果先做身份及完成度核验，满足同协议的可复用，不以方便为由全重跑；历史不同硬件/不完整训练不能伪装成严格控制的新批次。

正式目标仍是NWPU与BigEarthNet的M0/M1/M3多seed均值/样本SD及配对差，拟用42/43/44固定训练seed与固定split。BigEarthNet已有第四seed45继续保留于既有表，不隐去；若新架构只做三seed，其配对表明确限定42/43/44，不能与四seed平均值直接配对。导师最新要求优先于旧规则“只对两个模型多seed”；不能因为单seed负面就宣称三模型多seed要求已完成。

首轮完整耗时和实际卡价返回前不给总费用。每个付费批次启动前明确现有结果复用范围、运行次数、预计时长及最高预算；若预算不支持后续重复，保留单seed结论并明确论文要求仍未完成，不挑好seed补表。

## 7. 论文产物与可支持的结论

- NWPU：OA、macro-F1、逐类accuracy、混淆矩阵；BigEarthNet：主要mAP，次要macro/micro-F1及逐类AP，固定阈值。
- 三核心模型的均值/样本SD、每seed配对差和参数/同设备效率。一次涨分不能写成稳定提升；训练seed重复不等于重新抽取数据集划分。
- 同一固定验证样本上的原图、硬分区、软分配热图/熵、捕获图边和模型分数；样本先按固定seed选取并保留失败例，不按test挑图或调参数。
- 只有7×7 token分配，展示上采样不能冒充像素级分割；无区域标注时，图像看起来更整齐也不是“语义正确”的定量证据。
- 模型末端线性汇总的限制、局部空间先验、区域同质化及负结果写入讨论。若M3没有优于M1/M0，应据实报告，不以“新增模块”代替贡献证据。

## 8. 本次设计核验与实施边界

已用标准库核算49个位置的局部候选与初始质量：候选数4/6/9分别覆盖9/24/16个token，16区域初始质量最小1.03、最大4.203333；行和均为1，无初始空区域。参数和张量字节数如上。此核算不是PyTorch前后向测试，也没有GPU训练。

已自查：分配与汇总归一化维度不同；软反馈不经过argmax；空间边明确为先验；共同初始化、旧权重兼容和冻结对照都有验证要求；统计范围不混用旧协议或删负结果。首版实现文件/测试步骤将在设计审阅后编排，不在本草案中附可直接启动的训练命令。
