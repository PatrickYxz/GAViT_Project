# E05实施建议：局部区域原型软分配

2026-09-26。用户确认设计并批准继续实施；[实现计划](../plans/2026-09-26-local-prototype-soft-assignment.md)的本地阶段现已完成，新分组、软反馈、metadata、双入口与诊断已接通。独立审阅修复后完整CPU回归190项通过，见[验收记录](../../../results/soft_assignment_local_validation.md)。未提交/推送、未部署服务器或启动GPU训练，精度收益尚未验证。本文替代09-25草案中的分配器与首批实验安排；预算与真实数据可用性在服务器运行前落实。

## 1. 决定与目的

采用**局部区域原型软分配**。一个token根据自己与当前图片附近区域代表特征的相似性，学习如何归属；保留Swin-T、16区域、现有GAT、48+32边构造规则和残差反馈后的分类头。

理由：局部候选保留空间依据，图结构易于解释；当前图片的区域原型使分配显式依赖区域内容；单次计算便于控制复杂度。其方向参考[SSN与STViT源码核对](../../soft_assignment_github_review_20260926.md)，计算细节是本项目适配，不声称完整复现任何外部模型。

问题限定为：**整套软分组机制相对固定分组，能否改善分类表现，且开销是否值得？** 不承诺提升，不将软分配自身当作原创贡献。首批不同时比较多个分配器，也不增加新的损失、反馈门控或骨干层级。

## 2. 具体计算

输入`X∈R[B,49,768]`，区域数16。`h(i)`沿用当前7×7到4×4的硬归属，但只用于初始原型和局部候选，不作为最终归属。

1. **原型汇总权重。** 复用旧版`attn`标量网络计算`a_i`，在每个旧硬区域内按token做softmax得到`W0[i,k]`。不新增或取消原注意力网络。
2. **可学习特征空间。** `Z_i = normalize(Linear(LayerNorm(X_i)))`。LayerNorm维度768、eps=1e-5；Linear为768→128、无bias、Xavier-uniform初始化；L2 normalize的eps=1e-6。投影参数与骨干一起通过原任务损失学习。
3. **当前图片的区域原型。** `C_k = normalize(Σ_i W0[i,k] Z_i)`，L2 eps同上。原型每次forward由当前图片计算，不是跨图片的可学习类别中心；保留经`W0`与`Z`的梯度。
4. **软归属。** token i只考虑旧锚点网格上距`h(i)`切比雪夫距离≤1的区域。候选内`L[i,k]=(Z_i·C_k)/0.1`，候选外`-inf`；`log S=log_softmax_k(L)`，`S=exp(log S)`。温度0.1为首版预先固定值，非已验证最优；本轮无温度学习、退火或搜索。只做一次分配，不迭代更新原型。
5. **最终区域特征。** 保留原重要性加权：`W[i,k]=softmax_i(log S[i,k]+a_i)`，`R_k=Σ_i W[i,k]X_i`。S沿区域归一化、W沿token归一化，输出R维度仍为`[B,16,768]`。
6. **图与反馈。** R进入原图构造/GAT/feedback projection得到F；`T_i=Σ_k S[i,k]F_k`，`X'_i=X_i+T_i`，接原mean pool和classifier。训练、推理都保持软归属，不用argmax或no_grad计算分配。

取消旧草案的90%/10%先验、输出区域编号的MLP和零末层初始化。局部候选本身提供空间限制；不再额外引入位置偏置系数。

单个新投影模块的静态参数为`2×768+768×128=99,840`；不是此前MLP候选的102,032。batch32单个FP32的S仍为100,352字节；总显存/时间不能由此推断。

## 3. 保留的边界与风险

- 48条固定边表示锚点邻接先验，32条特征边按新R重新选取。局部候选不保证语义纯净、实际轮廓接壤或区域连通；不把这些当成已实现能力。
- 7×7 token分配的展示分辨率有限，不声称像素级分割。反馈后立即mean pool，最终反馈为`Σ_k(m_k/49)F_k`，`m_k=Σ_i S[i,k]`；没有额外逐token细化网络。
- 原型包含本区域token，会有自相似倾向；旧区域大小4/2/1不等。它们是需检查的偏置，不能预先认定导致失败或通过临时加正则掩盖。
- cosine/固定温度和局部mask使有效分数有界；零范数由normalize的eps处理。原型范数过低、区域表示趋同或分配不变化要记录诊断；非有限数值必须失败，不自动换分组器。
- 分配路径可微不代表top-2边选择可微。原图的离散选边规则保留，连续节点/反馈路径承担梯度。

## 4. 接口与兼容

新分组名`soft_prototype`，首版仅支持K16、N49、`sparse_hybrid`和`token_feedback`；其他组合明确拒绝。旧默认值和旧checkpoint行为保留。

新分组返回`(R,S)`；旧分组继续返回`(R,hard_indices)`。GAViT按显式配置选择矩阵映射或原gather分支，校验形状、dtype和候选合法性。诊断接口按需捕获S/W/W0、原型范数与图边，不长期保存带梯度缓存。

必须写入metadata并据其重建的配置：

| 字段 | 取值 |
|---|---|
| assignment_version | local_prototype_cosine_v1 |
| assignment_dim | 128 |
| assignment_radius / metric | 1 / chebyshev |
| assignment_temperature | 0.1 |
| assignment_iterations | 1 |
| assignment_projection | shared_ln_linear_no_bias |
| assignment_init | xavier_uniform |
| assignment_norm_eps / ln_eps | 1e-6 / 1e-5 |
| prototype_pooling | fixed_region_attention |
| region_pooling | attentive_log_membership |
| feedback_mapping | soft_membership |
| graph_node_geometry | anchor_index_prior |

共享参数初始化与原固定GAViT逐键核对；投影使用独立可复现的随机作用域，避免新增层改变GAT/分类头初值和数据顺序。正式实验从共同预训练骨干开始，不由不同旧任务checkpoint继续训练。

需联动修改分组、GAViT前向、单标签入口和runner的架构校验/校准→refit传递，以及BigEarthNet train/test的metadata与重建。缺失新字段、CLI冲突或不同架构续训报错。旧NWPU入口若不接入新模式则明确拒绝，正式新NWPU协议使用scene入口。

## 5. 验证顺序与判断

### 本地先完成

- S行和1、W列和1、mask外0；batch维隔离和eval重复一致。
- 在可控输入下验证token与原型变化能影响S；分别证明投影、骨干、原注意力能通过分配路径收到有限且非零的梯度。不能只依赖原骨干直通分类分支的梯度证明分配可学习。
- one-hot归属代入时，与旧汇总/反馈/logits一致；原模型与旧checkpoint回归保持。
- 覆盖零向量、相反向量、相同token、区域大小不等、错误N/K以及非有限输入；不要求相同token输入产生非零分类差异。
- 真实图构造方向、80条非自环构造边、去重与重载一致。运行资源测试与源码检查分开报告。

### 再在服务器短测

优先NWPU固定小样本1 epoch，再BigEarthNet固定小样本1 epoch；只验路径、标签、预训练、前后向和存盘重载。记录第一batch、退出状态、资源与时间。短测分数不作为收益依据。

### 然后只跑一个候选

NWPU先seed42，在同一清单/配方下比较Swin、固定GAViT和本版本。先做train/val校准；主要指标val OA，辅以macro-F1、分配质量与效率。先核验有无可复用的同协议结果，旧70/15/15近似成绩不能充当新baseline。

工程错误先修复；分配不变化/区域同质化且无验证收益时先分析已有输出，不立即扩多seed；有效且有研究价值时再冻结正式配置、安排refit/test和BigEarthNet seed42。小幅增益不等于稳定提升，不因单seed结果反复试温度或挑种子。

BigEarthNet工程短测与之后的完整30轮任务分开，完整任务须先有耗时和预算安排。对负结果如实保留；如果暂停后续批次，仍明确导师要求的双数据集、多seed消融未完成，不能以省费为由把它标记完成。

每轮在固定验证样本记录S熵、区域质量/argmax占用、原型范数/相似度、相对同一探针初始S的变化、反馈范数、val指标和耗时。诊断不使用test调参。

## 6. 首批比较与最终论文要求

首批只有三种核心模型：M0 Swin、M1固定4×4 GAViT、M3本版软分配GAViT。它检验整个软分组机制的作用，不能单独分离软化、内容依赖和新增参数的贡献。

旧草案建议的M2冻结90%/10%不进入首批。若后续确需区分机制，再预先定义一个明确问题及单独预算的对照；冻结投影并不冻结S，因为骨干和原型仍变化，不能将其命名为固定分配。只在推理时改S也不是独立训练消融。

最终仍须覆盖NWPU/BigEarthNet三模型及多seed均值/样本SD、配对差、效率和案例。NWPU清单预期5040/1260/25200、refit6300，须真实prepare核验；BigEarthNet沿用237871/122342/119825和已有冻结配方。既有结果优先复用，但须身份及完成度可比。正式多seed沿用42/43/44；已有BigEarthNet45全部保留，不能将三seed新版本与四seed旧平均值直接配对。
