## 6. 汇报中可使用的结论

当前证据显示，类别收益与损失同时存在，且对比较对象、seed、数据集和评价范围敏感。NWPU图册中的预测纠正没有形成对应类别全测试集的统一提升；BEN soft43的主要AP收益集中在沙滩和海岸湿地，同时草地/工业/复杂耕作退步。固定区域图的类别得失与soft替代的得失分开叙述，不能将分类变化直接等同于语义分组改善或特定图边的因果效果。

若需支撑指定四seed的“哪些类别稳定受益/受损”，仍需42/43/46/47对应完整per_class与预测/混淆数据；当前NWPU43和新46/47均没有本地完整逐类回传。先整理已有测试工件，不为本次分析重训。
