## 论述边界

1. Swin已具有上下文交互；本研究检验新增区域归纳偏置的价值。
2. 固定版学习组内池化，不学习成员边界；soft版是局部锚点约束的一次图像内原型分配，不包含Gaussian prior或FFN诊断候选。
3. soft的S与W沿不同轴归一化；48+32条指pre-GAT显式非自环边；cosine用于选拓扑，GAT另学聚合权重。
4. GloRe、TokenLearner/TokenFuser、两种STViT等已有聚合、交互和映回的先例。正文不将这一通用组织方式宣称首创，也不把两个同缩写模型混为一篇。
5. 当前AID/NWPU使用校准后重新初始化refit；BEN测试验证mAP best。早期其他split和混合执行条件结果不静默并入统一协议主表。
6. HGTNet和DFAGCN是直接相关完整方法。DFAGCN已有独立组件及CPU检查，完整训练与统一协议对比仍未完成；正文不把组件测试升级为论文实测。
7. 当前四章不填造稳定提升、语义分割、显著性或外部方法成绩。独立推论与文献已有结论保持清楚归属。
