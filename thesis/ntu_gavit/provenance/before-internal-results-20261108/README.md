## 论述边界

1. Swin已具有上下文交互；本研究检验新增区域归纳偏置的价值。
2. 固定版学习组内池化，不学习成员边界；soft版是局部锚点约束的一次图像内原型分配，不包含Gaussian prior或FFN诊断候选。
3. soft的S与W沿不同轴归一化；48+32条指pre-GAT显式非自环边；cosine用于选拓扑，GAT另学聚合权重。
4. GloRe、TokenLearner/TokenFuser、两种STViT等已有聚合、交互和映回的先例。正文不将这一通用组织方式宣称首创，也不把两个同缩写模型混为一篇。
5. 当前AID/NWPU使用校准后重新初始化refit；BEN测试验证mAP best。早期其他split和混合执行条件结果不静默并入统一协议主表。
6. HGTNet和DFAGCN是直接相关完整方法。HGTNet×NWPU/AID、DFAGCN×NWPU的独立实现seed42实测和预测复算均已完成，单列为补充比较。共享冻结划分不等于统一训练配方；原作者官方复现、统一协议及多seed外部比较均未由本章建立。
7. AID三模型全部5000条原始路径/标签/类别顺序已经核对。HGTNet相对固定GAViT纠正75张、新增76张，共同正确4771张、共同错误78张；净少对1张。NWPU HGTNet比固定GAViT净多对4张，目前缺该对原始逐图向量，不能由净数推断其纠正/新增错误数。两项都不构成显著或稳定优势，外部单seed不并入内部多seed均值和SD。
8. AID HGTNet的恢复调用耗时/显存不能当全实验总资源，服务器checkpoint重载及SHA证据不称本地模型重载。独立推论与文献已有结论保持清楚归属。
